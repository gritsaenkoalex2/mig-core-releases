МИГ — Центр управления 0.3.0

Обзор связи, управление локальными моделями LM Studio, встроенный стенд без терминала и сохранённые отчёты. Исправлен запуск подготовки обновления Windows. Поддержан защищённый адрес Tailscale для телефона вне дома; нужна однократная настройка сети на обоих устройствах. Установить поверх существующего ядра, без удаления настроек.

Телефонный профиль и действия через диалог доставляются отдельным OTA для Android 1.0.5 после проверки. Проверки Windows используют макет модели; живой Qwen и связь телефона вне дома проверяются отдельно.
