МИГ — Центр управления0.4.0.

- Встроенный сервис llama.cpp для Windows CPU/Vulkan: каталог Qwen3 4B/14B и Nomic, проверенные загрузки с докачкой, импорт существующего GGUF. После настройки можно работать без LM Studio; прежний сервис остаётся доступным.
- Постоянные вкладки моделей, отдельный тест сравнения текстов для Nomic. Галерея приложений: МИГ и явно обозначенные макеты робота-компаньона/МИГ Питание.
- Совместимое обновление телефона подключает общие действия локальной модели: предложение, проверка приложением, Сохранить/Отмена, фактический результат и отмена последнего изменения.
- Карточки профиля используют общий редактор, крестик и кнопки. Одно поле имени и отдельное ты/вы.

Для телефона нужен соответствующий OTA пакета1.0.5; новый APK не требуется. Сначала обновите Центр управления. Данные приложения не удаляются.

CI проверяет установку/перезапуск Windows и интерфейс с макетом модели, отдельно реальный CPU движок и Nomic GGUF. Это не приёмка качества Qwen14B или видеокарты пользователя. Работа вне дома требует однократной настройки Tailscale и проверки на устройствах.
