МИГ — ядро 0.2.5

Редактирование инструкции общения с сохранением и восстановлением, фактическая версия в интерфейсе, отдельная передача исходных реплик пользователя и календарный справочник, сведения об авторе проекта. Скачивание показывает прогресс, повторно использует проверенный файл и поддерживает докачку. Отдельный процесс подтверждает готовность перед закрытием ядра; журнал фиксирует установку и перезапуск. Подписанный канал дополнительно передаёт SHA256 приложения для проверки результата установки.

Режим чтения сохранён. Проверки Windows используют модель-макет; качество беседы с конкретной локальной моделью и установка на устройстве пользователя проверяются отдельно. Телефон обновляется OTA для runtime 1.0.5; новый APK не требуется.
