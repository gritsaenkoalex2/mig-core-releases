# МИГ — Центр управления 0.4.0 · Windows x64

Центр управления обслуживает локальные модели, личное подключение МИГа и встроенный стенд. Модели работают на этом компьютере. Платный облачный GPT не используется.

## Модели

В «Мои модели» выбери сервис: существующий LM Studio или встроенный. Настройки LM Studio сохраняются при переключении. Встроенный сервис устанавливает проверенный llama.cpp b12212 для Windows x64: Vulkan для совместимой видеокарты либо CPU. Перед загрузкой на GPU освободи память прежней модели LM Studio. CPU работает медленнее.

В каталоге: авторские GGUF Qwen3 4B/14B и Nomic Embed Text1.5 с закреплёнными версиями, размерами и SHA256. Можно импортировать свой существующий GGUF: файл не копируется и не удаляется при исключении из списка. Назначение — диалог либо поиск по смыслу. Загрузка из интернета, загрузка в память и начало диалога — отдельные действия; прогресс и отмена видны. Есть докачка, проверка свободного места и хэша. Движок не содержит веса: 14B скачивает около9ГБ,4B около2.5ГБ. Память при работе зависит от модели и контекста, начальный контекст16K.

После загрузки диалоговой модели она назначается моделью МИГа. Nomic сравнивает тексты: отдельная кнопка тестирует близость запроса и примеров, но не ведёт беседу. Автоматический поиск по базе МИГа через embeddings пока не подключён. TTS, картинки и другие архитектуры потребуют отдельных движков следующих выпусков.

Постоянные вкладки «Мои модели / Каталог / Проверка» сохраняются при переходе в тестовый чат. Этот чат не подключён к базе телефона. Настройки позволяют запускать выбранную модель вместе с Центром управления. «Завершить работу» останавливает управляемые процессы; закрытие в трей продолжает обслуживать телефон.

## Приложения и подключение

Галерея: реальный МИГ и явно обозначенные макеты Робот-компаньон/МИГ Питание. Для каждого видны подключения, инструкции, журнал, проверки. Макеты не подключают устройства. Общий журнал относится к системе, журнал МИГа — к его последнему аутентифицированному запросу.

Открой «Приложения → МИГ → Подключения», выбери адрес домашней сети и включи доступ. Перенеси строку подключения в телефон: «Настройки → Общие → Подключения». Она содержит секретный ключ; не публикуй её. Для доступа вне дома поддерживается Tailscale: компьютер и телефон нужно однократно подключить к одной защищённой сети, выбрать адрес100.x и проверить телефон через мобильный интернет. Это отдельная приёмка на устройствах. Список адресов обновляется без перезапуска. Порты роутера открывать не нужно. Телефон и сервер шифруют сообщения, проверяют время/направление/повторы; подключение привязано к одному профилю за сеанс.

## Действия и профиль

Телефон показывает предложения модели: создание/изменение задач, сведений, настроек и прочих команд действующего каталога. «Сохранить» применяет проверенное предложение, «Отмена» отклоняет. Только фактический результат приложения означает сохранение. «Отмени последнее изменение» действует в этом диалоге и не затирает позднейшие ручные изменения. Сервер сам не пишет в базу телефона. Данные полей не считаются инструкциями. Облачного обходного маршрута нет.

Карточки профиля используют общий редактор, крестик и кнопки. Одно поле «Имя», отдельный ты/вы. При двух ранее сохранённых именах редактор предлагает выбрать одно; устаревшее поле архивируется после сохранения. Сведения и стиль передаются в следующем запросе.

## Проверки и обновления

Встроенный стенд:33 сценария/291 вопрос, быстрый26; вымышленные данные, отдельные чаты, JSON/TXT автоматически сохраняются в bench-results. Проверка не обучает веса и не меняет телефон. Точное совпадение не означает полную смысловую оценку.

Обновления проверяются при запуске и раз в6часов; установка только после кнопки. Докачка, общий предел2часа/3минуты простоя, подпись канала и SHA256. Перед закрытием Центр управления ждёт готовности установщика. Журналы: update-install.json, update-error.txt, update-launch.stdout.txt, update-launch.stderr.txt в папке данных. Резерв — официальный установщик поверх прежней установки, без удаления пользовательских данных.

CI проверяет настоящий NSIS и повторную установку с перезапуском, UI/шифрованный транспорт и макет модели. Отдельно запускается настоящий CPU llama.cpp с маленьким GGUF без LM Studio. Это не проверка семантики Qwen14B, видеокарты пользователя или жестов реального Android; для них нужна отдельная приёмка.
