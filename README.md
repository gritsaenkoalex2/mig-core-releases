# МИГ — Центр управления 0.3.0 · Windows x64

Устанавливается поверх существующего ядра в ту же папку. Настройки и данные телефона сохраняются. Действительную версию показывает интерфейс. Подпись канала Ed25519 и SHA256 защищает обновление; установщик пока без сертификата издателя Windows.

## Начало работы
В разделе «Модели» укажи локальный адрес LM Studio, проверь связь, выбери текстовую модель и сохрани. Список скачанных моделей позволяет загрузить/выгрузить модель через нативный API LM Studio v1. Для запуска сервиса из Центра управления нужна однократная настройка утилиты lms в LM Studio. Отдельное окно LM Studio после настройки не обязательно, но установленный сервис и файлы моделей нужны. Загрузка новых моделей, TTS, камера и обучение весов в этом выпуске не встроены.

## Подключение телефона
В «Приложения» выбери адрес домашней сети, включи подключение и скопируй строку. В МИГе на телефоне: профиль → Настройки → Общие → Подключения. Строка содержит секретный ключ: не публикуй её. Включённый адрес восстанавливается при перезапуске, если он доступен. Отозвать подключение означает остановить доступ и заменить ключ.

Дома используется домашняя сеть. Для доступа вне дома поддерживается Tailscale: его нужно один раз установить и подключить к одной защищённой сети на компьютере и телефоне. Выбери адрес Tailscale в «Приложения» и перенеси новую строку в МИГ. При работающем компьютере и модели проверь соединение с телефона через мобильный интернет, отключив Wi-Fi. Это отдельная приёмка, не выполненная CI. Windows может потребовать разрешение приложения в брандмауэре; порты роутера открывать не нужно. Tailscale использует VPN-слот Android и может конфликтовать с другим VPN.

Сообщения дополнительно шифруются XSalsa20-Poly1305, проверяются время, направление и повторы. Сервер обслуживает один профиль за сеанс подключения; это личный сервер, ещё не массовая многопользовательская инфраструктура. Проверка связи не вызывает модель и не доказывает качество её ответов.

## Профиль и диалог
Четыре карточки «Обо мне»: основные сведения, ориентиры, сохранённые сведения, предложения МИГа. Направления, цели и привычки открываются отдельно. Имя, предпочитаемое имя и ты/вы — разные настройки; свежие основные поля приоритетнее старых свободных записей. Следующий запрос передаёт актуальные сведения и стиль.

Первые действия через диалог: «Запомни обо мне: ...», «Зови меня ...», «Обращайся ко мне на вы», «Всегда отвечай кратко», «Забудь: точный текст», «Отмени последнее изменение». Телефон применяет только явно распознанную команду после аутентифицированного ответа; подтверждение показывается после сохранения. Отмена не затирает сведения, изменённые позднее. Задачи пока только читаются. Нет скрытого облачного GPT.

## Проверки
Встроенный стенд открывается из «Проверки и обучение», терминал не нужен. Изолированные вымышленные данные, отдельные чаты сценариев, 33 сценария / 291 вопрос; короткий прогон по-прежнему 26 вопросов. Отчёты JSON/TXT автоматически сохраняются в папке bench-results внутри данных программы. Совпадение точного эталона не является полной смысловой оценкой; обучение весов — будущий отдельный процесс.

## Обновления и диагностика
Настройки → Проверить обновления. Скачивание поддерживает докачку, общий предел 2 часа и 3 минуты простоя без данных. До закрытия программы установщик должен подтвердить готовность. Журналы: update-install.json, update-error.txt, update-launch.stdout.txt, update-launch.stderr.txt в папке данных. Неудачная проверка запрещает установку. Первый переход использует загрузчик установленной версии; при его сбое официальный установщик запускается поверх вручную, без удаления данных.

CI проверяет настоящий Windows-установщик и его повторную установку, интерфейс, встроенный стенд и зашифрованный обмен с макетом LM Studio. Тесты не заменяют живой прогон Qwen и Android-приёмку. Общий журнал не содержит тексты чатов; последний запрос приложения доступен отдельно и может содержать личные данные.
