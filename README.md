# МИГ — настольное ядро

Публичные установщики Windows и подписанный канал обновлений. Текущая версия: **0.2.1**, Windows x64.

[Скачать установщик 0.2.1](https://github.com/gritsaenkoalex2/mig-core-releases/releases/download/v0.2.1/MIG-Core-Setup-0.2.1-x64.exe) · [Проверки и контрольные суммы](https://github.com/gritsaenkoalex2/mig-core-releases/releases/tag/v0.2.1)

## Переход с 0.1

1. Закройте старое ядро кнопкой «Завершить работу ядра».
2. Запустите установщик и выберите прежнюю папку. Удалять программу и настройки не нужно.
3. Оставьте LM Studio с загруженной моделью и сервером Running. В ядре проверьте подключение, выберите модель и сохраните.

Модели в установщик не входят и повторно не скачиваются. Версия 0.1 требует одного ручного перехода; в 0.2 последующие обновления предлагаются при запуске и раз в 6 часов: «Обновить / Позже». Установщик скачивается и запускается только после согласия. Проверяются Ed25519-подпись описания, размер и SHA256 файла. Android обновляется отдельно.

## Подключение МИГа на телефоне

Нужна отдельная Android-сборка с режимом «Моё ядро». Телефон и компьютер — в одной домашней сети. В ядре: «Приложения» → выбрать домашний адрес → «Включить подключение» → «Скопировать строку подключения». В МИГе: Настройки → «Моё ядро» → вставить строку, подтвердить передачу снимка и сохранить.

Строка содержит секретный ключ: не публикуйте её. При перезапуске ядра сетевое подключение нужно включить снова. LM Studio оставьте доступным локально; Интернет-доступ к ядру не требуется.

Режим первого этапа — только чтение ограниченного снимка задач, проектов, целей, направлений, регулярных дел и привычек. Запись/удаление моделью, голос и анализ изображений не подключены. Облачный GPT в новой Android-сборке отключён без автоматического переключения обратно в облако. Полная база, заметки, люди и места не отправляются.

Вкладка «Инструкции» показывает базовые правила, пакет МИГа и фактический последний запрос модели. Просмотр и полученные снимки хранятся в памяти процесса.

## Проверки

Опубликованный Windows-установщик прошёл установку, запуск реального приложения, UI, HTTP-чат с тестовой моделью, просмотр инструкций, зашифрованный LAN-запрос и удаление в GitHub Actions. Квитанции приложены к релизу. Это не заменяет проверку настоящего Qwen, телефона и домашней сети пользователя.

Установщик пока без Authenticode-подписи издателя Windows. Подпись канала обновлений — отдельная проверка; антивирус отключать не требуется.
